# Portofolio Ketut Sandhi Ardhitya

Website portofolio pribadi milik Ketut Sandhi Ardhitya, mahasiswa Ilmu Komputer Universitas Pendidikan Ganesha (Undiksha).

Website ini menampilkan informasi singkat mengenai profil, riwayat pendidikan, proyek yang pernah dikerjakan, serta kontak yang dapat digunakan untuk berkomunikasi.

## Demo

Website dapat diakses melalui GitHub Pages:

[https://sandhi1469.github.io/Portofolio_sandhi/](https://sandhi1469.github.io/Portofolio_sandhi/)

## Fitur

- Halaman profil pribadi
- Navigasi smooth scroll
- Navigasi responsif untuk perangkat mobile
- Riwayat pendidikan dalam bentuk timeline
- Daftar proyek yang pernah dikerjakan
- Tautan menuju desain Figma
- Tautan menuju aplikasi kalkulator FCR dan IP kandang ayam
- Tombol telepon dan WhatsApp
- Tampilan responsif untuk desktop, tablet, dan mobile
- Highlight navigasi berdasarkan posisi scroll

## Teknologi yang Digunakan

- HTML5
- Tailwind CSS
- JavaScript
- Google Fonts
  - Spectral
  - IBM Plex Sans
  - IBM Plex Mono
- SVG untuk elemen dekorasi visual
